# 📸 Image Collaboration Tool

A real-time platform for teams to collaborate on images with 
pin-based comments, share links, and admin moderation tools.

## Features
- 🔐 User authentication (signup/login)
- 📤 Upload and share images
- 📍 Pin-based comments with real-time updates
- 🔗 Share links with expiration dates
- 👑 Admin dashboard with user/content moderation
- 📧 Email notifications for new comments/replies

## Tech Stack
- Frontend: React, Vite
- Backend: Node.js, Express
- Database: PostgreSQL, Prisma
- Real-time: Socket.IO

## Installation
1. Clone the repo
2. Run `npm install` in both frontend and backend
3. Set up your .env file
4. Run `npm run dev` in both folders
